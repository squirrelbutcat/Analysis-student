# Анализ влияния социальных сетей на студентов

Проект по разведочному анализу данных о влиянии использования социальных сетей на образ жизни и ментальное здоровье студентов.

В работе используется датасет Kaggle:

`shivasingh4945/student-social-media-and-mental-health-impact`

Цель проекта — исследовать, как время, проведённое в социальных сетях, связано с различными показателями студентов: качеством сна, уровнем стресса, физической активностью, учебной нагрузкой и другими доступными признаками.

В ходе работы выполнены загрузка и подготовка данных, очистка, исследовательский анализ, построение визуализаций и формирование итогового отчёта.

```text

│       └── analyze.py           # основной код анализа
│

```

## Установка

Создать виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установить необходимые библиотеки:

```bash
pip install -r requirements.txt
```

## Загрузка данных

Скачать датасет:

```bash
python scripts/download_data.py
```

Для загрузки используется библиотека `kagglehub`.

## Запуск анализа

Запуск основного анализа:

```bash
python src/student_analysis/analyze.py
```

Также можно передать путь к конкретному CSV-файлу:

```bash
python src/student_analysis/analyze.py --input путь_к_файлу.csv
```

## Результаты

После выполнения анализа формируются:

* очищенный датасет;
* сводные таблицы;
* статистика по признакам;
* анализ корреляций;
* графики;
* итоговый Markdown-отчёт;
* HTML-дашборд.

```text

```

## Вопросы анализа

В проекте рассматриваются следующие вопросы:

* сколько времени студенты проводят в социальных сетях;
* какие платформы используются чаще всего;
* есть ли связь между временем в социальных сетях и качеством сна;
* как использование социальных сетей связано со стрессом и показателями ментального здоровья;
* есть ли различия между группами студентов по доступным характеристикам.
